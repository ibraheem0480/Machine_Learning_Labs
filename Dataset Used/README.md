This directory serves as the centralized storage folder for all raw and external datasets utilized across the machine learning and deep learning laboratory curriculum. It archives the primary time-series energy logs, including the hourly electrical load sequences from the American Electric Power (AEP) dataset, alongside multi-class plant pathology image matrices (covering healthy corn, common rust, northern leaf blight, and cercospora) and structural calendar references required for macro-environmental holiday feature engineering. Centralizing these assets within a designated data directory ensures absolute path consistency across all sequential training, preprocessing, and model deployment execution workflows.
