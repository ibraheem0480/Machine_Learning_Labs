# 📊 Lab 02 – Introduction to Data Analysis Libraries

> **Machine Learning Laboratory** | Building the foundation of Data Science with **NumPy**, **Pandas**, and **Matplotlib**

---

## 📖 Overview

This laboratory introduces three of the most essential Python libraries used in Data Science and Machine Learning. The exercises provide hands-on experience with numerical computation, data manipulation, and visualization, forming the basis for future machine learning applications.

The lab consists of three Jupyter notebooks, each focusing on a core Python library widely used in AI and analytics workflows.

---

## 🎯 Learning Outcomes

Upon successful completion of this laboratory, students will be able to:

- Create and manipulate numerical arrays using **NumPy**
- Perform indexing, slicing, and matrix operations
- Build and manage **Pandas** Series and DataFrames
- Load and inspect datasets from CSV files
- Filter and analyze tabular data efficiently
- Generate professional visualizations using **Matplotlib**
- Customize charts with titles, labels, legends, and grids
- Understand the importance of data analysis in machine learning pipelines

- Random number generation
- Statistical computations

- Grouping operations
