Lab 03 (Parts 1, 2, and 3) for the Machine Learning Lab course, demonstrating comprehensive time-series data preprocessing and feature engineering pipelines applied to the American Electric Power (AEP) hourly energy consumption dataset. Across the three modules, the project establishes structural data integrity by converting timestamps to datetime objects and auditing missing operational records (Part 1), cleanses extreme anomalies by implementing an Interquartile Range (IQR) outlier detection method followed by continuous time-based linear interpolation (Part 2), and engineers domain-specific features by parsing and merging external calendars to map the impact of institutional holidays on consumer power grid behaviors (Part 3).
