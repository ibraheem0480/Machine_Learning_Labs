
Lab 05 for the Machine Learning Lab course, focusing on the implementation of advanced data preprocessing pipelines, normalization, and partitioning strategies for time-series forecasting datasets. The workflow features the implementation of scikit-learn preprocessing architectures—including MinMaxScaler and StandardScaler for numeric feature engineering and OneHotEncoder for categorical serialization—alongside the utilization of custom time-series cross-validation modules (t_v_t_split) to cleanly partition sequential energy load matrices into independent training, validation, and testing configurations while protecting sequential dependency and avoiding data leakage.
