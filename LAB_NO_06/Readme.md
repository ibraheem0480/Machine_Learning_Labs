
Lab 06 (Parts 1, 2, and 3) for the Machine Learning Lab course, focusing on regression architectures, optimizations, and generalization dynamics. The project models physical environments—specifically Ohm's Law and synthetic projectile motion data—by pairing Scikit-Learn linear regression estimators with evaluation metrics like Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE) (Part 1), implementing a custom, scratch-built batch gradient descent optimization routine operating on normalized data spaces before rescaling back to raw physical units (Part 2), and conducting an empirical study on model generalization boundaries by analyzing structural underfitting and overfitting states using high-degree polynomial curves (np.polyfit) (Part 3).
