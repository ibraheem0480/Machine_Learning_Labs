Lab 07for the Machine Learning Lab course, focusing on automated image dataset preprocessing and structured directory pipelines for Computer Vision tasks. The workflow handles structural data partitioning of plant disease imagery—specifically isolating categories such as healthy corn, common rust, and northern leaf blight—by utilizing Python's os and shutil modules to dynamically construct independent training, validation, and testing directory trees, map balanced image distributions across folders, and programmatically relocate physical image assets to establish a clean, standardized pipeline optimized for deep learning and convolutional neural network (CNN) model training.
