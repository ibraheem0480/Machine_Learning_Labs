
Lab 12 for the Machine Learning Lab course, focusing on high-performance temporal modeling using recurrent architectures for multi-step time-series forecasting. The workflow implements Long Short-Term Memory (LSTM) networks using Keras/TensorFlow to capture complex, long-term sequential dependencies across the American Electric Power (AEP) hourly energy consumption dataset, utilizing windowed slicing methods (multivariate_multi_step, univariate_multi_step) to handle complex input-output dimensions and rigorously validating the forecast accuracy with key performance indicators including Mean Squared Error (MSE), Root Mean Squared Error (RMSE), Mean Absolute Percentage Error (MAPE), and Median Absolute Percentage Error (MDAPE).
