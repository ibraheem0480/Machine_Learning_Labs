## 📌 Repository Overview

This repository contains a series of laboratory exercises designed to provide practical experience with Machine Learning and Deep Learning concepts. Each lab focuses on solving real-world problems using industry-standard libraries while emphasizing experimentation, visualization, and model evaluation.

Whether you're a student, researcher, or AI enthusiast, these notebooks serve as a comprehensive learning resource for understanding modern Artificial Intelligence workflows.

---

## 🎯 What You'll Learn

Throughout this repository, you will gain practical experience in:

- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data Cleaning & Preprocessing
- ⚙️ Feature Engineering
- 🤖 Machine Learning Model Development
- 🧠 Deep Learning using TensorFlow & Keras
- 🖼 Computer Vision with CNNs
- 📈 Time-Series Forecasting
- 📉 Model Evaluation & Performance Analysis
- ⚡ Energy Demand Forecasting using CityLearn
